## ส่วนที่ 1 — สำหรับร้าน

### 1. ติดตั้งแอป (Android 7.0 ขึ้นไป)

1. เปิดลิงก์ไฟล์ `KooChang-0.2.15-build17.apk` ที่ทีมงานส่งให้ บนมือถือ แล้วกดดาวน์โหลด
2. กดเปิดไฟล์ ถ้าขึ้น "ไม่อนุญาตให้ติดตั้งจากแหล่งนี้" ให้กด **ตั้งค่า → อนุญาตจากแหล่งนี้** แล้วกดย้อนกลับ
3. ถ้า Google Play Protect เตือน "ผู้พัฒนาที่ไม่รู้จัก" ให้กด **รายละเอียดเพิ่มเติม → ติดตั้งต่อไป** (แอปยังไม่อยู่บน Play Store ระหว่างทดลอง)
4. รุ่นใหม่ติดตั้งทับรุ่นเดิมได้ ข้อมูลไม่หาย

### 2. เริ่มใช้งาน (เจ้าของร้าน ทำครั้งเดียว ~5 นาที)

1. **สมัคร**: ใส่เบอร์มือถือ → รับรหัส OTP ทาง SMS → ตั้งรหัสผ่าน (ครั้งต่อไปเข้าด้วยเบอร์ + รหัสผ่าน)
2. **สร้างร้าน**: ตั้งชื่อร้าน ได้ทดลองใช้ฟรีตามระยะที่กำหนด
3. **ชวนช่าง** (ถ้ามี): แท็บทีม → ส่งลิงก์/QR ให้ช่าง → ช่างสมัครแล้วกดขอเข้าร่วม → เจ้าของกดอนุมัติ
4. **ข้อมูลออกใบเสร็จ**: หน้าแรก → การ์ดแพ็กเกจ → ต่ออายุ / เลือกแพ็กเกจ → เลื่อนลงที่ ข้อมูลออกใบเสร็จ / ใบกำกับภาษี (ชื่อ, เลขผู้เสียภาษีถ้ามี, ที่อยู่)

### 3. งานประจำวัน

- **ลูกค้าใหม่**: ค้นด้วยเบอร์ → ไม่เจอให้กดเพิ่มลูกค้า → บันทึกที่อยู่ (กดใช้ตำแหน่งปัจจุบันได้ตอนอยู่หน้างาน)
- **เครื่อง/อุปกรณ์**: ถ่ายรูปป้ายเครื่อง ระบบช่วยอ่านยี่ห้อ/รุ่น/Serial ให้ ตรวจแล้วกดบันทึก
- **เปิดงาน**: เลือกลูกค้า → เครื่อง → วันนัด → มอบหมายช่าง
- **จบงาน**: กรอกผลบริการ + รูปก่อน/หลัง → ตั้งรอบดูแลครั้งถัดไป → ระบบเตือนเมื่อถึงรอบ
- ไม่มีสัญญาณ: ดูงาน/ลูกค้า/เครื่องที่เคยเปิดได้ รูปผลบริการจะส่งเองเมื่อมีสัญญาณ

### 4. ชำระเงินแพ็กเกจ

- หน้าแรก → การ์ดแพ็กเกจ → ต่ออายุ / เลือกแพ็กเกจ → เลือกแพ็กเกจ → จ่ายด้วย **บัตร** (ครั้งเดียว หรือตัดบัตรอัตโนมัติทุกรอบ) หรือ **โอนเงิน + แนบสลิป** (ระบบตรวจสลิปและเปิดสิทธิ์ทันที)
- ราคารวม VAT 7% แล้ว · ใบเสร็จรับเงิน/ใบกำกับภาษีออกให้อัตโนมัติ เปิด PDF ได้ในหน้าแพ็กเกจ
- ยกเลิกการต่ออายุได้ตลอด ใช้ได้ถึงสิ้นรอบที่จ่ายแล้ว

### 5. ติดปัญหา

- ในแอป (เจ้าของร้าน): แท็บบัญชี → ช่วยเหลือ → พิมพ์ปัญหา ทีมงานตอบภายใน 1 วันทำการ (จ.–ศ. 09:00–18:00)
- บอกรุ่นแอปด้วย: บัญชี → เกี่ยวกับแอป
