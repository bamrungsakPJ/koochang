คู่ช่าง Mobile v2

ผลตรวจแอปรุ่น 0.2.16 ทุกหน้า ทั้งฝั่งเจ้าของร้านและช่าง ตามที่บอกมา 4 เรื่อง: หาเมนูไม่เจอ งานหลักของช่างหลายขั้น หน้าตาไม่เป็นมืออาชีพ และเจ้าของกับช่างปนกัน พร้อมหน้าจอที่เสนอ ลำดับการทำ และสิ่งที่ต้องตัดสินใจ

สิ่งที่เจอในแอปตอนนี้

หาเมนูไม่เจอ / ลำดับหน้างง
  • แพ็กเกจกับใบเสร็จอยู่ในการ์ดท้ายหน้าแรก ต้องเลื่อนผ่านงาน ทีม รอบดูแล แล้วกด “ต่ออายุ / เลือกแพ็กเกจ” และเลื่อนลงอีกจึงเจอใบเสร็จ
  • รอบดูแลเข้าได้จากการ์ดหน้าแรกทางเดียว ไม่มีในแท็บ
  • ช่วยเหลืออยู่ในแท็บบัญชี ปนกับภาษาและรหัสผ่าน
  • ปุ่มย้อนกลับไปที่ตายตัว เช่น เปิดงานจากแจ้งเตือนแล้วกดกลับไปหน้ารายการงาน, เปิดงานใหม่จากหน้าเลือกลูกค้าแล้วกดกลับไปหน้าลูกค้า (ปุ่มย้อนกลับ 28 จุดกำหนดปลายทางไว้ตายตัวในโค้ด)
  • มีหน้าที่ไม่มีทางออก เช่นหน้า “ยังไม่ได้อยู่ในร้านใด” (แก้แล้วใน 0.2.16)
งานช่างหลายขั้น
  • บันทึกผลงานที่ได้รับมอบหมาย ต้องเปิดงานก่อน แล้วค่อยกดบันทึกผล ไม่มีปุ่มบนรายการงาน
  • ทุกเครื่องต้องเลือกเองทุกช่อง: ประเภทงาน ผลงาน รอบดูแลถัดไป แม้งานจะบอกประเภทไว้แล้ว และเครื่องมีรอบเดิมอยู่
  • งานนอกแผนต้องค้นลูกค้าทุกครั้ง ไม่มีรายการลูกค้าล่าสุด
  • ปุ่ม “เสร็จงาน” ตามด้วยหน้าสรุปอีกหน้า ต้องกดตกลงอีกครั้ง
หน้าตาไม่เป็นมืออาชีพ
  • ไอคอนใช้ 7 สีปนกัน (ฟ้า เขียว ม่วง ชมพู ส้ม…) โดยสีไม่ได้บอกความหมาย ทุกอย่างจึงดูสำคัญเท่ากัน
  • หน้าแรกเจ้าของมี 8 กล่องต่อกัน: แถบน้ำเงินใหญ่ แจ้งเตือน ปุ่มงานนอกแผน งานของฉัน ตัวเลขทีม รอบดูแล ทีม แพ็กเกจ
  • ปุ่มเต็มความกว้างซ้อนหลายปุ่ม ไม่รู้ว่าปุ่มไหนคือสิ่งที่ควรกด
  • สถานะงานเป็นตัวหนังสือเล็ก ไม่เห็นในพริบตาว่างานไหนเลยเวลา งานไหนเสร็จ
เจ้าของกับช่างปนกัน
  • หน้าแรกเดียวกัน ต่างกันแค่เจ้าของมีกล่องจัดการต่อท้าย
  • เจ้าของที่มีช่างหลายคนเห็น “งานของฉัน” เป็นอย่างแรก แทนภาพรวมงานทั้งร้านวันนี้
  • ร้านคนเดียว (เจ้าของทำงานเอง) ได้แท็บทีมที่แทบไม่ได้ใช้
  • ช่างเห็นแท็บลูกค้าทั้งร้าน แทนลูกค้าที่เกี่ยวกับงานตัวเอง

ผลจากการอ่านโค้ดทุกหน้า (App.tsx และ screens/*) ยังไม่ได้วัดกับผู้ใช้จริง

หลักที่ใช้ออกแบบใหม่

  • หน้าแรก = สิ่งที่ต้องทำวันนี้

    งานวันนี้ก่อนเสมอ เรื่องร้าน เงิน แพ็กเกจ ขึ้นหน้าแรกเฉพาะตอนต้องทำอะไรบางอย่าง

  • หน้าละหนึ่งปุ่มหลัก

    ปุ่มหลักอยู่ล่างจอตำแหน่งเดิมทุกหน้า ปุ่มรองเป็นตัวหนังสือหรือปุ่มอ่อน

  • สีบอกความหมาย

    กรมท่า = กดได้ / สำคัญ, ส้ม = กำลังทำ, เขียว = เสร็จ, แดง = เลยเวลา ไอคอนอื่นเป็นสีเทาเดียวกัน

  • กลับที่เดิมเสมอ

    ปุ่มย้อนกลับ (และปุ่มกลับของ Android) พากลับหน้าที่มาจริง ไม่ใช่หน้าที่กำหนดไว้

  • ใส่ค่าที่รู้อยู่แล้วให้

    ประเภทงานจากใบงาน, ผล = เสร็จ, รอบดูแลจากรอบเดิมของเครื่อง ช่างแก้เฉพาะที่ต่างไป

เมนูแยกตามบทบาท

ช่าง

งานวันนี้ลูกค้าฉัน
งานวันนี้แสดงลำดับตามเวลา มีปุ่ม “นำทาง” และ “บันทึกผล” บนแต่ละงาน ปุ่มลอย “+ บันทึกงาน” สำหรับงานนอกแผน ลูกค้าแสดงลูกค้าที่เคยทำงานด้วยก่อน

เจ้าของร้านที่มีทีม

วันนี้งานลูกค้าร้าน
วันนี้ = ภาพรวมทั้งร้าน (งานเลยเวลา งานที่ยังไม่มีคนรับ คำขอเข้าร่วม) แท็บร้านรวม ทีม รอบดูแล แพ็กเกจและใบเสร็จ ช่วยเหลือ ตั้งค่าร้าน บัญชีส่วนตัวย้ายไปที่รูปโปรไฟล์มุมบน

เจ้าของที่ทำงานคนเดียว

วันนี้ลูกค้าร้าน
ไม่มีแท็บทีมและงานแยก งานวันนี้ใช้หน้าเดียวกับช่าง และมีปุ่มเปิดงานใหม่ เมื่อชวนช่างคนแรก เมนูจะเปลี่ยนเป็นแบบมีทีมเอง

หน้าจอที่เสนอ

ภาพจำลองแสดงโครงหน้าและลำดับความสำคัญ ไอคอนและตัวเลขเป็นตัวอย่าง ของจริงจะใช้ไอคอนชุดเดิมของแอปและข้อมูลจริงของร้าน

งานหลักต้องกดกี่ครั้ง

งานตอนนี้ที่เสนอเปลี่ยนอะไร
ช่างบันทึกผลงานที่ได้รับมอบหมาย (1 เครื่อง, ล้างตามใบงาน)9 ครั้ง4 ครั้ง กด “บันทึกผล” บนรายการงาน → ถ่ายรูปก่อน → ถ่ายรูปหลัง → เสร็จงานตอนนี้: เปิดงาน → บันทึกผล → ประเภท → ผล → รูปก่อน → รูปหลัง → รอบถัดไป → เสร็จงาน → ตกลงหน้าสรุป
ช่างบันทึกงานนอกแผน ลูกค้าที่เคยทำ7+ ครั้ง และพิมพ์ค้นหา5 ครั้ง ปุ่ม “+ บันทึกงาน” → เลือกจากลูกค้าล่าสุด → รูป 2 รูป → เสร็จงานตอนนี้ต้องพิมพ์ค้นเบอร์หรือชื่อลูกค้าทุกครั้ง
เจ้าของดูใบเสร็จ / ใบกำกับภาษีเลื่อน 2 หน้า + 2 ครั้ง2 ครั้ง แท็บร้าน → ใบเสร็จ / ใบกำกับภาษี
เจ้าของต่ออายุแพ็กเกจที่ใกล้หมดเลื่อน + 2 ครั้ง1 ครั้ง กด “ต่ออายุ” บนแถบแจ้งเตือนหน้าแรก (ขึ้นเฉพาะช่วงใกล้หมด)

นับจากขั้นตอนในโค้ด ไม่รวมการพิมพ์และการเปิดกล้อง ตัวเลข “ที่เสนอ” เป็นเป้าหมายที่จะวัดอีกครั้งหลังทำเสร็จ

ลำดับการทำ (แต่ละขั้นได้ APK ให้ลองบนมือถือ)

  • โครงเมนูใหม่และหน้าแรกแยกบทบาท

    แท็บตามบทบาท, หน้าวันนี้ของช่างและเจ้าของ, แท็บร้าน (ทีม รอบดูแล แพ็กเกจ ใบเสร็จ ช่วยเหลือ), ย้ายแพ็กเกจออกจากหน้าแรก, ปุ่มย้อนกลับกลับหน้าที่มาจริง

  • บันทึกผลแบบเร็ว

    ปุ่มบันทึกผลบนรายการงาน, ค่าที่ใส่ไว้ให้ (ประเภท ผล รอบเดิม), ปุ่ม “+ บันทึกงาน” กับลูกค้าล่าสุด, ตัดหน้าสรุปเป็นข้อความสั้นแทน

  • ระบบหน้าตา

    สีไอคอนชุดเดียว สีบอกสถานะเท่านั้น, ปุ่มหลักติดล่างจอ, ขนาดตัวอักษรและระยะห่างชุดเดียวทั้งแอป, ทำทุกหน้าที่เหลือให้เป็นแบบเดียวกัน

ไม่ต้องแก้ API หรือฐานข้อมูลในขั้น 1 และ 3 ขั้น 2 อาจเพิ่ม API เล็กน้อย (ลูกค้าล่าสุดของช่าง, รอบเดิมของเครื่องใน job)

ต้องให้ตัดสินใจ

  • ช่างควรเห็นลูกค้าทั้งร้าน หรือเฉพาะลูกค้าที่เคยทำงานด้วย?

    ตอนนี้เห็นทั้งร้าน ข้อเสนอคือเรียงลูกค้าของตัวเองก่อน แต่ยังค้นทั้งร้านได้ (งานนอกแผนอาจเป็นลูกค้าใหม่)

  • ปุ่มลอย “+ บันทึกงาน” มุมขวาล่าง ตกลงไหม?

    ทางเลือกคือปุ่มกลางแถบเมนู แบบปุ่มลอยไม่เปลืองช่องเมนู

  • หน้าสรุปหลังเสร็จงาน ตัดออกได้ไหม?

    เสนอให้แสดงข้อความสั้น “บันทึกแล้ว · รอบถัดไป 9 เม.ย. 2570” แล้วกลับหน้างานวันนี้เอง

  • เริ่มขั้น 1 ได้เลยไหม?

    ขั้น 1 ส่งผลกับทุกคนมากที่สุด และไม่ต้องแก้ฝั่งเซิร์ฟเวอร์
