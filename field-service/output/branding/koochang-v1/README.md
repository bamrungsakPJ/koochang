# KooChang / คู่ช่าง — logo concept v1

Created 2026-10-05. Original raster design generated with the imagegen skill.

## Files

- `logo-horizontal.png`: horizontal KooChang wordmark with transparent background, for light website headers.
- `app-icon.png`: standalone symbol on an opaque pale background, full square without an outer rounded mask.
- `splash-screen.png`: portrait static startup composition. This is a screen design, not an animated loading component.

## Design

Two rounded parts form a K and a negative-space wrench jaw. The two parts represent the shop and technician working together. Teal communicates reliability; orange adds warmth and energy. The symbol uses minimal detail for small-screen recognition.

## Usage and status

These are versioned PNG design assets, not editable vector masters. Preserve aspect ratio. Use the symbol without lettering for app icons. The splash composition should be adapted to each screen ratio rather than stretched. Export platform-specific sizes and adaptive-icon layers when integrating.

Images were visually reviewed; final vector geometry, exact palette, tiny-size readability, and device rendering remain to be checked during production preparation. Existing website and mobile assets have not been replaced, and no deployment was performed.
