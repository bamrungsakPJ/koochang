# KooChang — selected B symbol color study v4

2026-10-05: User preferred v3 design B (upper K arm is an open-end wrench) and requested a more striking palette based on color principles.

`palette-comparison.png` compares three color directions using the same selected B concept and a dark-background app-icon treatment.

## Proposed palette targets

| Option | Base / wordmark | Accent / wrench | Icon stem |
| --- | --- | --- | --- |
| 1 | Midnight navy `#12243A` | Amber orange `#F5A623` | Off-white `#F8FAFC` |
| 2 | Forest `#123D32` | Marigold `#F6BE32` | Off-white `#F8FAFC` |
| 3 | Indigo `#30265B` | Aqua `#31D7C3` | Off-white `#F8FAFC` |

Use a dark stable base, a brighter accent on the tool, and ample negative space. On dark icon backgrounds the vertical K stem becomes off-white so it remains visible. Colors are chosen for hue separation and luminance hierarchy; no claim is made that a color guarantees trust or purchases. The accent is not intended as body text on white.

These hex values are production targets; generated raster colors may differ. The sheet is a visual study, not separate final application assets. No app/web replacement or deployment. Shape and exact color consistency must be finalized in the master assets after selecting a palette.
